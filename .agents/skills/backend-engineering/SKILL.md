# Backend Engineering Skill

Use this skill when implementing backend services.

## Architectural Layers
- **Routes**: Define REST endpoints under `/api/v1`.
- **Controllers**: Validate payload parameters and delegate to services.
- **Services**: Implement core domain logic, algorithms, and business rules.
- **Repositories**: Encapsulate Mongoose model queries and persistence.
- **Models**: Define Mongoose schemas with indexing and timestamps.
- **Middleware**: Error handling, JWT authentication, rate limiting, and CORS.
