# Testing Skill

Use this skill when developing automated test suites.

## Scope
1. **Unit Tests (Vitest)**:
   - Price calculation formulas (nights, cleaning fees, taxes, discounts).
   - Date formatting and nights diff utilities.
   - AI Concierge NLP intent parser and ranking score algorithms.
2. **Component Tests (React Testing Library)**:
   - Sticky booking card calculations and date changes.
   - Gallery component interactions.
   - Modal open/close and keyboard listeners.
3. **E2E Tests (Playwright)**:
   - User journey 1: Homepage loads -> Photo tour open -> Lightbox next/prev -> Esc close.
   - User journey 2: Reservation card date selection -> Price recalculation -> Reserve action.
   - User journey 3: AI Concierge query -> Parsed filters -> Recommendation list -> Booking modal handoff.
