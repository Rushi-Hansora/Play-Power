# UI Implementation Skill

Use this skill when implementing UI components.

## Guidelines
- Follow Airbnb design tokens: Coral `#FF385C`, Charcoal `#222222`, Soft Gray `#717171`, Border Gray `#DDDDDD`.
- Use functional React components with clean prop types or interfaces.
- Use Tailwind CSS utilities for layout, spacing, flexbox, and CSS grid.
- Integrate Lucide React icons cleanly with consistent stroke widths (1.75 - 2).
- Keep components modular: extract subcomponents when files exceed ~250 lines.
