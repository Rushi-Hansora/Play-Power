# DevOps Skill

Use this skill when configuring deployment workflows and CI/CD pipelines.

## Pipeline Steps
1. **Frontend CI**: Lint -> Vitest -> Vite Build.
2. **Backend CI**: Lint -> Unit tests -> Health endpoint check.
3. **Deploy Validation**: Verify production bundle sizes, asset hashing, and zero missing environment variables.
