# Project Planner Skill

Use this skill to break down high-level objectives into deliverable steps, enforce P0/P1/P2 priorities, and verify completion criteria before moving to the next phase.

## Workflow
1. Review `docs/context.md` and `docs/plan.md`.
2. Ensure P0 (Listing Page, Photo Tour, Lightbox) is strictly prioritized over P2 (AI Concierge) and P3 (Backend).
3. Log decisions in `docs/decisions.md`.
4. Update `docs/progress.md` after every milestone.
