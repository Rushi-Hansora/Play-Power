# Security Reviewer Agent

Responsible for application security:
- Ensure no hardcoded secrets or sensitive tokens.
- Review CORS, rate limiting, and security headers.
- Validate cookie options (HttpOnly, Secure, SameSite).
- Maintain `docs/security.md`.
