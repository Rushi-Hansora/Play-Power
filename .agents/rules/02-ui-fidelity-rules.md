# 02 — UI Fidelity & Interaction Rules

- The provided reference (`https://airbnb-clone-umber-two.vercel.app`) is the visual specification.
- Visual elements to match:
  - Header search pill bar with rounded borders and box-shadow on hover.
  - Sub-navigation scrollspy bar (`Photos`, `Amenities`, `Reviews`, `Location`) that becomes fixed/sticky on scroll past hero with the reservation snapshot.
  - 5-photo hero gallery with border radii and hover darkening effect.
  - "Show all photos" floating button with grid icon.
  - Full-screen Photo Tour overlay with categorised sections and close button.
  - Lightbox modal with arrow navigation, image counter `X / Y`, and Escape dismissal.
  - Sticky reservation card with exact borders, shadow, date and guest selectors, and price math.
  - Location section with styled map canvas, pin marker, and neighborhood highlights.
- Preserve micro-interactions, active states, hover transitions, and clean typography.
