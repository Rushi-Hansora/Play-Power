# 00 — Project Rules

- Never copy or scrape source code or assets from the reference implementation.
- Prioritize P0 requirements (Listing Page, Photo Tour, Lightbox) before adding differentiating features.
- Prefer simple, robust solutions over unnecessary layers of abstraction.
- Document architectural and technical decisions in `docs/decisions.md`.
- Keep `docs/progress.md` updated with real-time progress.
- Never commit secrets, credentials, or private API keys to version control.
