# Airbnb Clone — Project Context & Instructions

## Project
PlayPower Labs Airbnb Clone take-home assignment.

## Primary Objective
Recreate the provided Airbnb listing reference with extremely high visual and behavioral fidelity.

Required experiences:
1. Listing Page
2. Photo Tour (Full-screen categorized gallery)
3. Lightbox (Single-photo viewer with keyboard controls)

The assignment specification is the source of truth.

## Priority Framework
- **P0** = Assignment requirements (Listing Page, Photo Tour, Lightbox)
- **P1** = Visual fidelity, typography, spacing, micro-interactions, accessibility
- **P2** = Differentiator: AI Travel Concierge prototype
- **P3** = Code quality, modular React, clean state management
- **P4** = Testing (Unit, Integration, E2E)
- **P5** = Backend foundation (Node.js, Express, MongoDB, Mongoose)
- **P6** = DevOps (GitHub Actions CI/CD, deployment readiness)

Never sacrifice P0 for additional features.

## Critical Originality Constraint
The reference website (https://airbnb-clone-umber-two.vercel.app) is strictly a visual and behavioral specification.
- DO NOT copy source code
- DO NOT copy CSS classes or stylesheets
- DO NOT scrape the reference
- DO NOT copy copyrighted assets
Implement everything cleanly and independently.

## Core Tech Stack
- Frontend: React 19, Vite 8, React Router, Tailwind CSS, Motion for React, Lucide React, Axios, TanStack Query, Context API
- Backend: Node.js, Express, MongoDB, Mongoose, JWT auth
- Testing: Vitest, Testing Library, Playwright

## Engineering Standards
- SOLID principles
- Clean separation of concerns (Presentation vs Container vs Services)
- Accessible interactive components (ARIA, focus traps, keyboard shortcuts)
- Structured logging & centralized error handling
