# Project Context — Airbnb Listing Experience Clone

## Executive Overview
This project is an independently engineered, pixel-conscious recreation of the Airbnb listing experience developed for the PlayPower Labs Full-Stack Take-Home Assignment.

The reference implementation at `https://airbnb-clone-umber-two.vercel.app` serves strictly as a visual and behavioral specification. In full compliance with originality and academic integrity standards, no source code, stylesheets, or proprietary assets have been copied, scraped, or reverse engineered. All components, styles, data models, and business logic are written from first principles.

## Target Experience
1. **Listing Page**: Comprehensive property details page with responsive desktop layout, rich hero gallery, floating action controls, host details, sleeping arrangements, 45+ amenities, 19 reviews, interactive location map, and sticky reservation card with date and guest calculations.
2. **Photo Tour**: Full-screen modal presenting high-resolution photo categories with thumbnail navigation, keyboard controls, and smooth scrolling.
3. **Lightbox**: Single-photo viewer featuring previous/next navigation, counter display (`X / Y`), accessible labels, `Escape` key handling, and Motion animation between photos.
4. **Differentiator — AI Travel Concierge**: An agentic prototype allowing travelers to input natural-language constraints (budget, rating, distance, amenities) to receive ranked property recommendations with explainable reasoning and mock booking handoff.

## Priority Order
- **P0**: Core Assignment Requirements (Listing Page, Photo Tour, Lightbox)
- **P1**: Visual & Behavioral Parity, Accessibility (WCAG 2.1 AA), Engineering Quality
- **P2**: Differentiator: AI Travel Concierge Prototype
- **P3**: Full-Stack MERN Backend Foundation (Node.js, Express 5, MongoDB, Mongoose, REST APIs)
- **P4**: Testing & DevOps (Vitest, Playwright, GitHub Actions CI/CD)
